# Protab — Pitch Document

## The Paradigm Shift

> The "tabs" mental model was designed when most work happened *outside* the browser. Today, for knowledge workers, **everything** lives in the browser — documents, design tools, communication, research. But browsers still use the same 1990s paradigm: temporary, disposable tabs that accumulate into clutter.

> **Protab replaces the broken "tab" mental model with "projects"** — durable context containers that survive browser restarts, support deliberate focus, and eliminate the anxiety of closing windows.

---

## The Problem (Reframed)

**It's not just about too many tabs. It's about context switching.**

Every knowledge worker does dozens of context switches per day:
- Writing a document → research for a meeting → Slack → back to the document
- Each switch creates a new tab, fragments focus, and clutters the browser
- Closing the window feels risky because you might lose something
- But keeping everything open fragments attention and wastes resources

**The browser's "tab" paradigm is the bottleneck to focused work.**

---

## The Solution: Projects, Not Tabs

Protab introduces a new mental model:

| Old Paradigm (Tabs) | New Paradigm (Protab) |
|---------------------|----------------------|
| Temporary, disposable | Durable, persistent |
| Browser-wide, flat | Project-scoped |
| Passive accumulation | Active filing |
| Closing = anxiety | Closing = relief |
| Many open = productive | Few open = focused |

---

## The Core Workflow: File → Close → Focus

1. **File** tabs into projects (saves URL + metadata, closes the tab)
2. **Activate** a project (closes other projects' tabs, marks your focus)
3. **Reopen** only what you need, when you need it

**The result:** A clean browser window without losing anything, and the ability to focus on one project at a time.

---

## Emotional Benefits

1. **Relief** — "I can finally close this tab without anxiety"
2. **Safety** — "My important URLs are safe and won't get lost"
3. **Focus** — "I can finally concentrate on one thing at a time"

## Core Features

1. **Projects** — Container for related URLs with tags and notes
2. **Current Tabs Pane** — Live inventory of your browser window, grouped by project ownership
3. **Filing** — Drag-and-drop, hover shortcut ('A'), or file button to save tabs
4. **Quick Capture** — `Ctrl+Shift+X` popup for zero-friction capture from any tab
5. **Activation** — Explicit action to close other projects' tabs for focused work
6. **Protected Tabs** — Pinned, audible, or manually protected tabs are never closed
7. **Export/Import** — Self-contained HTML files that work offline
8. **Archiving** — Move completed work out of active view

---

## Technical Differentiators

- **Local-First** — No accounts, no sync, no server, no data leaves your browser
- **Manifest V3** — Modern Chrome extension architecture
- **Safe Close** — Confirmation dialogs, never silently closes tabs
- **Ownership Tracking** — Every live tab has at most one project owner
- **Schema Versioning** — Safe migration with backup recovery

---

## What Protab is NOT

- **Not a bookmark manager** — Project-scoped, includes close workflow
- **Not a read-it-later tool** — Active work context, not article queuing
- **Not a session manager** — Saves individual URLs, not entire browser sessions
- **Not a tab suspender** — Closes after saving, doesn't hibernate tabs
